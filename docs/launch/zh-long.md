## 正文

市面上的胶片 App，绝大多数做的事是：拿一张图，套一个精心调过的 LUT。
好看是好看的，但它不知道 Kodak Portra 400 在不同曝光下染料密度怎么变，也不知道
同一卷负片印在 Endura 和 Supra 相纸上为什么是两个颜色。

「照夜」想做的是另一件事：**把冲印这条链按物理走一遍**。

```
场景光 → 胶片曝光 → 显影（染料密度）→ 放大机 → 相纸 → 显影 → 扫描 → sRGB
```

这条链不是比喻。它来自 Andrea Volpato 的开源项目 spektrafilm——那里面有 28 套
**实测**片基配置：染料密度曲线是把真胶片送进分光光度计量出来的，不是调色调出来的。
Hanze Qiu 的 SpektraLab 把它移植成 C++/Vulkan（原本跑在 Apple 的 Metal 上），
我又把那套原生引擎接到了安卓上。

所以这个 App 里，你调的不是「强度」，是暗房里的真实动作：**曝光**是放大机的曝光时间，
**M/Y 滤色**是放大机头上的二向色滤片（CC 值），**颗粒**和**光晕**发生在胶片层，
改它们要重新冲一遍底片，而不是套个蒙版。

### 手机上能看出差别的地方

**片边是真的片边。** 很多人以为那是「相纸的白边」，其实相纸永远没有边。你看到的那圈带
齿孔、带片边字符、带 DX 条形码、带橙色日期后背的黑边，是**负片的片边**——未曝光的片基、
齿孔、"KODAK 400-8" 这样的型号字、以及相机后背烧上去的日期。把负片连边一起放进放大机，
才印得出那一圈。这部分在引擎里是 2300 行纯 C++ 数学：片门形状、齿孔、字符光栅化、
DX 码、漏光与灰雾，全都按真实胶片生成。

**日期后背读 EXIF。** 你的照片拍于 2025 年 8 月 24 日，片边上就烧 `'25 8 24`；
想改也行，改完标题会从「取自照片」变成「手选」。字是正立的——这一点曾经是个 bug，
我在验收文档里留了完整的定位过程。

**RAW 能直接进。** 走 LibRaw 0.22.2，ARW / NEF / CR2 / CR3 / DNG / RAF / ORF / RW2 都行。
42 MP 的 ARW 半尺寸 AHD 解码约 0.45 秒，峰值内存 253 MB——选半尺寸不是偷懒，全尺寸
峰值 688 MB，在 MIUI 上随时会被杀，而 3984 px 已经高于导出用的 3200 px。

### 快不快

在一台小米 MIX FOLD（骁龙 888 / Adreno 660 / Android 11）上：

- 31 MP JPEG 源，切胶片/相纸：像素差 3.09，肉眼可见是真的换了乳剂
- 曝光 ±2 EV：整条管线重跑约 3 秒
- M/Y 滤色 ±30 CC：走重印快路径约 0.3 秒，且**确定性**——归零后与基线逐像素一致
- 导出 3200 长边：约 4 秒
- 最大能到 6400×4273（27 MP）

### 它现在还不好用的地方

- **只有 arm64-v8a，要 Android 8.0+ 且支持 Vulkan 1.1**，模拟器装不了。
- **片源原尺寸（42 MP）会掉线**：一张 float32 图 485 MiB，顶着手机 GPU 512 MiB 的缓冲上限，
  Adreno 660 会直接把设备踢掉。App 会自愈并退回 3200，但那张成片没了。根治要靠分块渲染，
  还没做，写在路线图里。
- **预览是同步的**，1600 px 一张要 3–5 秒，拖滑杆手感还偏硬。
- 只做了安卓。上游的 Metal / Windows 后端不在这个仓库里。

### 开源

GPL-3.0-or-later。引擎源码以裁剪副本的形式放在仓库 `engine/` 下，我对上游做的 10 个文件的
改动全在 `patches/0001-android-port.patch` 里，在上游某个 commit 的干净检出上 `git apply`
就能复现。胶片配置与 LUT 沿用 CC BY-SA 4.0，署名的两层都不能省，README 里写清楚了。

- 下载：https://github.com/Shawn-SU-1/zhaoye/releases/latest
- 源码：https://github.com/Shawn-SU-1/zhaoye
- 出问题请附诊断报告（设置页 →「导出日志文件」），里面有机型、GPU capabilities、
  最近 800 条事件和 logcat——同一版 APK 在不同 GPU 上表现差别可能很大，没有它基本没法定位。

### 为什么叫照夜

唐玄宗有一匹白马，一身白毛，黑夜里也照得见。韩幹给它画过像，那张《照夜白图》今天还在
大都会博物馆。暗房也是这样一间屋子：它黑着，得把光放进去，影才浮出来。

这个名字不是说要照亮照片，是说让一张底片在没有光的房间里，重新被照亮一次。
