## V2EX 版（技术向，发在 Share 节点）

**标题**：写了个安卓 App，在手机上用 Vulkan 跑完整的胶片冲印管线（开源）

**正文**：

不是滤镜。链条是「场景光 → 胶片曝光 → 显影 → 放大机 → 相纸 → 显影 → 扫描 → sRGB」，
用的是 Andrea Volpato 的 spektrafilm 里那 28 套**实测**片基数据（染料密度是分光光度计量出来的），
引擎是他 C++ 移植版 SpektraLab，我把它接到了安卓：C ABI → JNI，Metal 的四个 kernel 翻成 GLSL，
CoreGraphics/CoreText 那套光栅化用 393 行扫描线填充 + stb_truetype 替掉，RAW 走 LibRaw 0.22.2 静态链进 .so。

所以 App 里调的曝光是放大机曝光，M/Y 滤色是二向色滤片头的 CC 值。改片基上的参数要重冲，改印相参数只重印（约 0.3 秒，确定性）。

那圈带齿孔和日期后背的黑边，是负片的片边，不是相纸边框，2.3k 行纯 C++ 数学生成。

已知坑：42 MP 原尺寸导出会撞 512 MiB 存储缓冲上限掉线（已做自愈降级）；live 预览 3–5 秒偏硬。
只有 arm64-v8a + Android 8.0 + Vulkan 1.1，模拟器装不了。

GPL-3.0，上游改动全在一个 patch 里。

https://github.com/Shawn-SU-1/zhaoye

## 即刻 / 酷安版（一段话，口语）

在手机上开了间暗房。

不是套 LUT 那种——是真的把「场景光 → 胶片曝光 → 显影 → 放大机 → 相纸 → 显影 → 扫描」
这条链用 Vulkan compute 跑了一遍，28 套片基数据来自实验室实测，曝光是放大机曝光时间，
M/Y 是二向色滤片头的 CC 值。片边那圈齿孔、片边字符、DX 码、橙色日期后背，是负片的边，
不是相纸的边框（相纸永远没边）。

它现在还很糙：42 MP 原图导出会掉线，预览一张要 3–5 秒，得 Android 8 以上的 arm64 真机。
但它是我把「胶片」这两个字当真了做的一次尝试。开源，GPL-3.0。

https://github.com/Shawn-SU-1/zhaoye

## 小红书版（短、带钩子、标签）

**标题**：手机里开一间暗房｜不是滤镜

一直觉得市面上的胶片 App 差点意思——它们知道胶片*看起来*什么样，但不知道胶片
*为什么*长那样。

所以我做了个东西：把「场景光→胶片曝光→显影→放大机→相纸→显影→扫描」整条链，
用手机 GPU 真跑了一遍。28 套片基是实验室实测的染料密度，曝光滑杆就是放大机曝光时间，
M/Y 就是滤片头的 CC 值。

最上头的是片边：齿孔、片边字符、DX 码、烧在片基上的橙色日期后背——那不是相纸的白边，
相纸永远没边，那是负片的边。

目前只做了安卓，还得是支持 Vulkan 的真机，42MP 原图导出还会掉线（摊手）。
开源，欢迎来骂。
